# TillRecon

**Retail Financial Reconciliation & Revenue Assurance**

TillRecon is a financial reconciliation system
designed to identify discrepancies between
point-of-sale (POS) transactions and payment settlements.

## Problem

Retail businesses process payments across multiple
channels, creating reconciliation challenges.

TillRecon automates transaction matching,
discrepancy detection and financial reporting.

## Core Capabilities

- Financial transaction ingestion
- Transaaction validation
- Duplicate detection
- Automated reconciliation
- Partial settlement detection
- Financial exception management
- Multi-branch reporting
- Auditability

## Technology

- C++20
- CMake
- SQLite
- PostgreSQL
- Googletest
- Git

## Architecture

The application follows a modular architecture
with separation between business logic,
infrustructure and application services
